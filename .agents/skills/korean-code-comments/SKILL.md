# 한국어 코드 설명 주석

사용자가 지정한 코드 파일을 초보자가 이해하기 쉽게 만든다. 결과물은 해당 파일 안의 한국어 설명 주석이다.

## 작업 범위

- 지정된 경로가 이 프로젝트 안의 코드 파일인지 확인한다. 경로가 없거나 여러 파일을 가리키면 어떤 파일인지 질문한다.
- 주석을 어려운 로직에만 달지, 모든 함수와 주요 코드 블록에 달지 확인한다. 기존 영어 주석을 유지할지 한국어로 바꿀지도 사용자 지시가 없으면 질문한다. 답을 받기 전에는 해당 선택에 의존하는 편집을 하지 않는다.
- 지정된 파일과 동작을 이해하는 데 필요한 가까운 코드만 읽는다. 코드의 의도를 자료로 확인할 수 없으면 추측을 주석으로 쓰지 말고 사용자에게 구체적으로 질문한다.
- 주석은 관련 코드 가까이에 해당 언어의 올바른 주석 문법으로 추가한다. 무엇을 하는지보다 이해하기 어려운 이유, 데이터 흐름, 조건의 의미를 우선 설명한다.
- 주석을 달기 위해 실행 코드, 타입, 공개 API, 동작, 파일 구조를 바꾸지 않는다. 별도 수정이 필요해 보여도 이 작업에 섞지 말고 사용자에게 알린다.
- 개인정보, 비밀값, 확인되지 않은 제품 요구사항을 주석에 넣지 않는다.

## 확인과 마무리

- 편집한 파일의 변경 내용을 검토해 주석 외의 변경이 없는지 확인한다.
- 어떤 부분을 설명했는지 짧게 알리고, 확인이 필요한 코드 의도는 질문으로 남긴다.
